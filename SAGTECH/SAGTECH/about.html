About the HUB

One hub for architecture, infrastructure and documentation

SAGTECH IT SOLUTION exists because IT work rarely fits a single supplier. A platform needs its data model designed, its network and cloud hardened, and its business case written well enough to be funded. We do all three — and we keep the record of every engagement in one place.

Our mandate

Turn ambiguous IT requirements into artifacts a build team, an auditor or a funding panel can act on: diagrams, schemas, specifications and runbooks.

How we work

Discovery first, then design, then execution. Nothing is documented speculatively — every artifact traces back to a stated requirement and a stakeholder decision.

Who we serve

SMEs and enterprises modernising platforms, public-sector bodies with legacy systems, and postgraduate researchers who need rigour in their proposals.

A note on this hub's own technology

This HUB is delivered as a static front-end (HTML, CSS and JavaScript) that persists its records through a RESTful table API. The intended production stack for a SAGTECH-style platform is a PHP application tier over a MySQL relational database — the equivalent SQL for every operation in this hub is documented in README.md so the design can be re-implemented on LAMP/WAMP without redesign.

Intended app tier

PHP 8 (PDO, prepared statements, session-based auth)

Intended data tier

MySQL 8 / MariaDB with InnoDB and foreign keys

This demo's data tier

Platform RESTful table API (SQL-backed)
